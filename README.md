Для запуска веб-приложения необходимо:

Наличие установленного Docker и Docker Compose (Для windows/macOS наличие Docker Desctop)
Склонировать репозиторий git clone https://github.com/l1r1k/oop_cursovaya.git
Заполненные .env файл. Необходимо переименовать example.env в .env и заполнить его данными.
Запустить файл ./init-letsencrypt.sh для сборки всего приложения и установки первичных SSL сертификатов, далее CertBot автоматически будет обновлять сертификат каждый 12 часов

Запуск веб-приложения рассчитан на серверах на базе UNIX-подобных систем. На текущий момент веб-приложение запущено на хостинге Рег.ру на VPS под Ubuntu 24.04
